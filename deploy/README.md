# deploy — инфраструктура coffeely

VPS РФ (Timeweb / Selectel / Yandex Cloud), оплата в рублях.

## Планируемый стек деплоя

- Docker Compose: backend, PostgreSQL, Centrifugo, Caddy (TLS).
- Миграции: golang-migrate, применяются при деплое.
- Секреты: `.env` на сервере, в репо не попадают (см. корневой `.gitignore`).

## Требование из базы знаний (AIK-13, соло-режим)

Инфраструктура обязана работать почти без ухода: автоперезапуск контейнеров,
автопродление TLS, бэкапы Postgres по расписанию, алерты на почту/телеграм.
